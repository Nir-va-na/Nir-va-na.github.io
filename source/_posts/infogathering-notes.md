> 信息收集是渗透测试的第一步：先把目标摸清楚，再决定往哪走。本文为授权靶场 / CTF 学习记录，所有操作仅在自己搭建或获得授权的环境中进行。

## 一、域名与子域名

- `whois` — 查询域名与注册信息，后接主域名（接参数 `-H` 过滤法律条款）
- `subfinder` — 挖掘子域名，扩大攻击面（非 Kali 自带，要接参数 `-d`）
- `nslookup`（Windows 命令）— 检查是否有 CDN

## 二、端口扫描：nmap

`nmap` 扫描开放端口，后接 IP 地址或网段（用 `-sn` 参数简单扫描节省时间）。

| 参数 | 作用 |
| --- | --- |
| `-sT` | 全连接，建立完整的 TCP 连接，结果最准确，但易暴露 |
| `-sS` | 半开扫描，不建立完整连接，隐蔽性强 |
| `-sU` | UDP 扫描，针对使用 UDP 服务的端口，但速度慢，结果不确定 |
| `-p` | 全端口扫描，通常接 `-T4` 模板来加速 |
| `-sV` | 进行服务版本探测（用来针对） |
| `-O` | 进行操作系统指纹探测，判断操作系统类型 |

`masscan` 只专注扫描端口，通常与 `nmap` 结合使用：

```bash
masscan ip -p端口范围    # 如 0-65535
```

嫌太慢可以使用 `--rate` 参数。

## 三、指纹与防护识别

- `whatweb` — 识别网站技术指纹，接 `-v` 参数更详细
- `wafw00f` — 摸清网站是否装了防火墙，避免打草惊蛇，后接域名
  - 识别失败不等于没有防护

## 四、隐藏目录扫描

`dirsearch`（非自带）扫描网站隐藏目录与文件：

```bash
dirsearch -u 完整地址
```

---

工具只是手段，关键是知道**每一步拿到的数据能回答什么问题**：域名归属、攻击面大小、开放了什么服务、有没有 WAF、有没有遗漏的目录。
