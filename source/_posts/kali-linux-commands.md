## 一、目录与文件操作

- `pwd` — 显示当前所在目录绝对路径
- `cd` — 切换目录（只能去所在位置子目录）
- `ls` — 基础查看（可接参数 `-`）
  - `-l` 参数，详细信息（权限/时间）
  - `-a` 参数，查看隐藏文件
  - `-lh` 组合，一行行显示
  - `ls -lah` （实战首选）
- `mkdir` — 创建目录，格式：`mkdir 目录名`
- `touch` — 创建文件，格式：`touch 文件名`
  - `touch -t` 修改时间，例如：`touch -t 202610010900 文件名` → 2026 年 10 月 1 日 9:00
- `rm` — 删除文件/目录（使用参数），格式：`rm 文件名`

```bash
rm -r 文件夹
rm -rf 文件夹      # 强制删除
```

- `cp` — 复制文件，格式：`cp 源文件 新文件`
- `mv` — 重命名/移动文件

```bash
mv 源文件名 新文件名
mv 源文件路径 目标目录路径
```

- `clear` — 清屏

## 二、查看文件内容

- `cat` — 查看文件（小文件）/ 合并文件

```bash
cat 文件名
cat 文件一路径 文件二路径 > 新文件名
```

- `more` — 查看文件（大文件），格式：`more 文件名`
  - 空格翻页，回车加载，Q 键退出
- `head` — 查看文件前几行（默认十行）
  - `-n` 参数（选择查看行数），格式：`head -n 5 文件名`
- `tail` — 查看文件尾部（默认十行），同理 `head`
  - `-f` 参数（实时跟踪文件数据）
- `grep` — 搜索

```bash
grep 关键词 文件
命令 | grep 关键词
```

## 三、文件权限

`chmod` 修改文件权限，格式：`chmod 权限 文件名`

权限说明：一共十位，用后九位每三个表示一种身份的权限，分别是所有者、所属组、普通用户。`r` 查看权限，`w` 修改权限，`x` 运行权限。

- `r` 对应 4，`w` 对应 2，`x` 对应 1，`-` 对应 0
- 例如：`-rw-rw-r--` 对应数字 `664`

## 四、身份与提权

- `sudo` — 临时借用管理员身份，格式：`sudo 命令`
- `sudo su` — 切换成管理员身份

## 五、网络信息

- `ifconfig` — 查看网络信息
- `ip` — 查看网络信息
- `ping` — 测试连通性

## 六、服务管理

`systemctl` 服务管理，格式：`systemctl [动作] [服务名]`

| 动作 | 作用 |
| --- | --- |
| `status` | 查看服务当前运行状态 |
| `start` | 启动指定服务 |
| `stop` | 停止指定服务 |

---

命令不在多，在于手熟。配合 `命令 --help` 和 `man 命令` 随查随用，比死记参数靠谱。
